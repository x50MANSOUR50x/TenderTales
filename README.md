# TrendTales AI 🎧✨

> **Don't Read the Trends. Experience Them.**

Stop drowning in endless news feeds and disconnected headlines. **TrendTales AI** transforms the daily firehose of global news and internet trends into a single, personalized, audio-narrated story tailored specifically to your interests and preferred style.

---

## 🌟 Why TrendTales AI?

Every day, we are overwhelmed with information across social media, news portals, and tech blogs. Reading through dozens of articles takes time you don't have.

**TrendTales AI solves Information Overload:**
* **From Information to Narrative:** Replaces dry, isolated headlines with an engaging, connected story.
* **Hands-Free Experience:** Perfect for your morning commute, workout, or cooking dinner.
* **Fully Personalized:** Pick the topics you care about and skip the noise.
* **Tailored Delivery:** Choose how you want to hear today's events—as a thrilling mystery, sci-fi adventure, documentary, or lighthearted comedy.

---

## 🎧 Traditional News vs. TrendTales AI

| Feature | Traditional News Apps | TrendTales AI |

⚙️ Setup & Installation
Prerequisites
- Python 3.10+
- pip

Quick Start
1. Clone the repository:

```Bash
git clone [https://github.com/your-username/TrendTales-AI.git](https://github.com/your-username/TrendTales-AI.git)
cd TrendTales-AI
```
2. Set up virtual environment:
```Bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\\Scripts\\activate
```

3. Install dependencies:
```
Bash
pip install -r requirements.txt
```
4. Set environment variables:
```Bash
cp .env.example .env
# Add your API keys and configs inside .env
```
5. Run the app:
```
Bash
python main.py
```
